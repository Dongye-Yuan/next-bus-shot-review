# 团队镜头审核

面向已授权团队成员的私密审核工作区。使用 ChatGPT 登录，审核状态、选版、操作人和时间写入共享数据库，导入的素材保存在私有对象存储。素材和审核记录按项目归属，成员角色适用于整个工作区。

- 所有者和审核员可从「新建项目」输入片名，从空白项目开始。用「当前项目」下拉框切回《下一班车》示例或其他项目。
- 用「新增镜头」填写标题、描述和预览时长。拖动列表中镜头右侧的手柄可跨位置排序。打开镜头后也可用「上移」「下移」排序，并可编辑属性、导入、通过、退回和选用版本。
- 右侧预览按项目的镜头顺序和设定时长更新。未选版本的镜头保留占位。视频比设定时长长时会在镜头结束处切换，较短时会停留在末帧至镜头结束。
- 只读成员可以浏览镜头、播放预览及导出审核记录。
- 其他成员保存后，按「刷新团队记录」同步。在旧版本上提交修改会收到冲突提示。
- 从公开演示导入过的自定义素材，需要在团队工作区重新导入。

## 导出竖屏成片

在竖屏预览下方点「导出竖屏成片」。缺少选用版本时，可从提示列表返回对应镜头。生成时按当前排序及预览时长输出 720 × 1280 的 MP4。图片维持设定时长，较长视频在镜头结束时切换，较短视频延长末帧。视频的原声随成片保留。生成在支持 MP4 录制的桌面浏览器中进行，耗时约等于成片时长，期间请保持页面在前台。导出在本地浏览器进行，生成后点击「下载 MP4」。

## 部署配置

使用 Sites Worker，D1 绑定名为 `DB`，R2 绑定名为 `BUCKET`，迁移文件在 `drizzle/`。运行 `npm test` 后执行 `npm run build`。部署时使用 Sites 的用户身份验证和私密访问策略。生产配置需要 `OWNER_EMAIL`，可另行配置逗号分隔的 `REVIEWER_EMAILS` 或 `VIEWER_EMAILS`。成员还必须获得对应站点的访问权限。身份头只可信于 Sites 管理的入口。

团队素材最大 50 MB。预置演示素材来自《下一班车》的公开演示。通过「导出审核记录」可下载当前项目的镜头时间轴、审核意见和操作历史。素材文件独立存储，JSON 可用于归档审核信息。单个镜头的预览时长为 1–300 秒。工作区服务于同一团队，适合权限范围一致的内部审片；为不同客户隔离访问时，应部署独立工作区并配置各自的存储和授权。

## 邀请成员

所有者打开「邀请成员」，输入队友的 ChatGPT 登录邮箱，保存审核员或只读角色。再在私密站点的共享设置授权该邮箱，并复制邀请说明发送给队友。应用只管理审片角色。站点共享负责发放访问权限。撤销角色即时阻止应用访问，也可从站点共享名单移除对应邮箱。

## 角色参考、检查与返工

- 在「角色参考」上传正面、侧面、全身图，填写角色本人的辨识特征和本版服装。检查素材后确认该版本。参考图保存在项目内。更新设定时新增一个参考版本，现有镜头继续引用原版，直到重新绑定。
- 在镜头上绑定已确认的角色与视角。生成关键帧时使用这些参考图。图片通过后可单独「确认为关键帧」，供视频生成使用。视频服务生成 5 秒或 10 秒素材，成片按镜头设定时长处理。
- 在素材卡片标记角色、检查项和时间。点击记录可并排查看参考图和问题帧。AI 抽检会为图片检查一帧，为视频检查五帧，提示由人工复核。
- 已退回版本可「发起返工」。视频可沿用已确认的关键帧，或确认修订后的关键帧再生成。可查询任务并把结果保存为待审版，也可在此处导入外部修订素材。原版及退回记录会保留。
- FAL_KEY 和 OPENAI_API_KEY 是私密部署的服务端密钥，分别启用 fal 生成和 OpenAI 视觉抽检。配置密钥前可走手动标记和外部导入。提交生成或视觉抽检会把相关素材发送给对应服务。状态不明的生成任务不会自动重发。
- 《下一班车》的人工标签在 test/fixtures/consistency-labels.json，开发样例与验收样例分开。运行真实视觉检查后导出审核记录，执行 node scripts/evaluate-consistency.mjs <审核记录.json> 可分别统计漏检和误报。该小样用于试跑流程。

## 故事与分镜

从项目栏打开「故事与分镜」，可单独保存故事原文，再切换至「分镜表」。可逐行录入，也可粘贴带表头的电子表格或 CSV 文本。每行必填镜头编号、出场角色（空镜可填「无人」）、场景、景别与角度、动作、目标时长。对白和服装版本选填，服装留空时沿用已确认角色参考的服装。可先填入《下一班车》的四镜头样表体验。

可调整每行内容与顺序并保存草稿。点击「确认并创建镜头」后，按表格顺序一次性建镜，新镜头追加在已有镜头之后。每个项目可确认一份表。已确认表保留为原始分镜记录，可以打开对应镜头继续编辑时长、动作、角色参考与审核。出场角色列保存为分镜信息，实际使用的参考图在镜头里确认并绑定。

### 剧本

先保存原文，再在「剧本」复制提示词，交给你使用的 AI 生成带表头的 TSV。粘贴结果后可以逐场修改或新增场景，也可以直接手填。剧本包含场景、出场角色、动作、对白和剧情推进，对白可留空。保存修订草稿时，分镜提示词继续使用上一次确认的剧本。

确认剧本后，在「分镜表」复制分镜提示词。可选填镜头数量和总时长。将外部 AI 返回的表格贴回分镜表，修改并确认建镜。

### 使用外部图片或视频工具

在镜头内打开「生成关键帧」「生成视频」或「发起返工」，可复制完整提示词并按清单打开素材。视频使用该镜头已确认的图片作为图 1，工具只支持首帧时只需上传这张图。提示词会合并镜头描述、角色版本、视角、目标时长和已有的返工问题。可填写补充要求后重新复制。外部生成后从同一入口导回待审，返工会关联原版，使用的已确认关键帧也会留在新版记录。
