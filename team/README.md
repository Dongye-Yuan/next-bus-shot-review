# 团队镜头审核

面向已授权团队成员的私密审核工作区。使用 ChatGPT 登录，审核状态、选版、操作人和时间写入共享数据库，导入的素材保存在私有对象存储。素材和审核记录按项目归属，成员角色适用于整个工作区。

- 所有者和审核员可从「新建项目」输入片名，从空白项目开始。用「当前项目」下拉框切回《下一班车》示例或其他项目。
- 用「新增镜头」填写标题、描述和预览时长。拖动列表中镜头右侧的手柄可跨位置排序。打开镜头后也可用「上移」「下移」排序，并可编辑属性、导入、通过、退回和选用版本。
- 右侧预览按项目的镜头顺序和设定时长更新。未选版本的镜头保留占位。视频比设定时长长时会在镜头结束处切换，较短时会停留在末帧至镜头结束。
- 只读成员可以浏览镜头、播放预览及导出审核记录。
- 其他成员保存后，按「刷新团队记录」同步。在旧版本上提交修改会收到冲突提示。
- 从公开演示导入过的自定义素材，需要在团队工作区重新导入。

## 导出竖屏成片

在竖屏预览下方点「导出竖屏成片」。缺少选用版本时，可从提示列表返回对应镜头。生成时按当前排序及预览时长输出 720 × 1280 的 MP4。图片维持设定时长，较长视频在镜头结束时切换，较短视频延长末帧。视频的原声随成片保留。生成在支持 MP4 录制的桌面浏览器中进行，耗时约等于成片时长，期间请保持页面在前台。导出在本地浏览器进行，生成后点击「下载 MP4」。

## 部署配置

使用 Sites Worker，D1 绑定名为 `DB`，R2 绑定名为 `BUCKET`，迁移文件在 `drizzle/`。运行 `npm test` 后执行 `npm run build`。部署时使用 Sites 的用户身份验证和私密访问策略。生产配置需要 `OWNER_EMAIL`，可另行配置逗号分隔的 `REVIEWER_EMAILS` 或 `VIEWER_EMAILS`。成员还必须获得对应站点的访问权限。身份头只可信于 Sites 管理的入口。

团队素材最大 50 MB。预置演示素材来自《下一班车》的公开演示。通过「导出审核记录」可下载当前项目的镜头时间轴、审核意见和操作历史。素材文件独立存储，JSON 可用于归档审核信息。单个镜头的预览时长为 1–300 秒。工作区服务于同一团队，适合权限范围一致的内部审片；为不同客户隔离访问时，应部署独立工作区并配置各自的存储和授权。

## 邀请成员

所有者打开「邀请成员」，输入队友的 ChatGPT 登录邮箱，保存审核员或只读角色。再在私密站点的共享设置授权该邮箱，并复制邀请说明发送给队友。应用只管理审片角色。站点共享负责发放访问权限。撤销角色即时阻止应用访问，也可从站点共享名单移除对应邮箱。
